## About Me

I am an **Electronics and Communications Engineer (Class of 2025)** with a multidisciplinary engineering background. Since 2022, I have worked professionally in the software industry as a **Frontend & Full-Stack Developer**—both collaborating within agile product teams and delivering robust client applications independently as a freelancer.

My core competence bridges **hardware systems, telecommunications infrastructure, and scalable modern software architectures**:
- **Full-Stack Web Engineering:** Architecting scalable, accessible, and high-performance web applications using React, Next.js, TypeScript, Node.js, Express, and distributed databases (MongoDB, Neon PostgreSQL, Supabase).
- **Embedded Systems & IoT:** Developing firmware in C/C++, configuring microcontrollers, interfacing sensor buses (UART, SPI, I2C, CAN), and streaming hardware telemetry to cloud dashboards.
- **Telecom & Networks:** Analyzing cellular systems (4G LTE / 5G NR), enterprise network architectures (OSI & TCP/IP), dynamic routing protocols, and deep packet inspection.

> **Engineering Philosophy:** *"Engineering value is created at the intersection—where physical signals, communication protocols, and modern software architectures converge."*
