Frontend Engineer with 3+ years building React.js and Next.js applications. Specialized in scalable frontend architecture, performance optimization, and accessible UI development. Experienced in TypeScript, state management (Redux Toolkit, Zustand), and RESTful API integration within agile teams.

- **Designing reusable component systems** — Creating maintainable, scalable code architecture
